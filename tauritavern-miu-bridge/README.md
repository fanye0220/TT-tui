# MIU 推卡桥接（MIU Card Bridge）

给**酒馆（TauriTavern / SillyTavern）**用的扩展：把酒馆里的角色卡通过**手机本机回环端口**
（`127.0.0.1`）直接推送到 **MIU 安卓 App**。

- 不登录账号
- 不走云端、不上传服务器
- 数据只在你这台手机内部传输

---

## 一、前提

MIU 安卓 App（重新打包安装的那份）里：

> 设置 → **TT 互联** → 点「开启接收服务」

看到「接收服务运行中 · 端口 8791」就算准备好了。**别忘了这一步**，否则扩展会提示找不到接收服务。

## 二、安装扩展

### 方法 A：酒馆扩展面板安装（安卓推荐）

酒馆的「Install extension」只认 GitHub 地址，所以要先把**本文件夹**传到你的仓库里
（用你已经在用的那个就行：`https://github.com/fanye0220/APP`，version.json 就放在那儿）：

1. 打开 `https://github.com/fanye0220/APP` → **Add file** → **Upload files**
2. 把整个 `tauritavern-miu-bridge` 文件夹拖进去（保留这一层目录名），提交到 `main` 分支
3. 打开酒馆 → 「扩展」（Extensions）面板 → 点「Install extension」
4. 粘贴：

   ```
   https://github.com/fanye0220/APP/tree/main/tauritavern-miu-bridge
   ```

5. 装完刷新酒馆页面（或重启酒馆），扩展面板里会出现「MIU 推卡桥接」

### 方法 B：手动复制（桌面端最省事）

把整个 `tauritavern-miu-bridge` 文件夹复制到：

```
<酒馆数据目录>/default-user/extensions/tauritavern-miu-bridge/
```

然后重启酒馆。

## 三、使用

1. MIU 里先「开启接收服务」，记住端口（默认 8791）
2. 切到酒馆 → 扩展面板 → 「MIU 推卡桥接」
3. 端口填一样的（默认 8791），点「检测连接」，显示已连接即可
4. 点「推送全部角色卡」或「推送当前角色」
5. 切回 MIU → 「设置 → TT 互联」→ 点「导入待接收卡片」→ 按正常导入流程确认入库

## 四、常见问题

- **提示找不到接收服务**：MIU 那边没开启服务，或者服务被系统杀掉了，回 MIU 重新点一次「开启接收服务」。
- **推送很慢 / 中途失败**：安卓会在切到后台后冻结 App，建议一次推几百张以内，推完立刻切回 MIU 导入。
- **点击没反应、控制台报网络错误**：可能是酒馆外壳的 CSP 拦了 `127.0.0.1`，这种情况需要酒馆侧放开限制（属于酒馆应用本身的策略）。
- **导入后卡没出现**：检查 MIU 里有没有提示解析失败；PNG 卡片一般都能识别。
