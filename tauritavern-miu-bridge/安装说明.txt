MIU 推卡桥接 —— 安装与使用说明
========================================

【这是什么】
就是这个文件夹本身（5 个文件：index.js / manifest.json / style.css / README.md / 本说明）。
酒馆扩展没有“安装包”可下，也不需要编译——把整个 tauritavern-miu-bridge 文件夹
放进酒馆认的扩展目录，它就在了。
（同目录那个 TT扩展_MIU推卡桥接.zip 是它的压缩版，解压出来是同一个东西。）

【用之前必须先做】
打开 MIU 安卓 App -> 设置 -> 「TT 互联」 -> 点「开启接收服务」。
看到「监听 127.0.0.1:8791」才算准备好，否则扩展会提示找不到接收服务。

【安装方法 A：酒馆里装（安卓推荐，用你自己现成的仓库）】
酒馆的「Install extension」只认 GitHub 地址，所以先把这个文件夹传到你自己的仓库里。
你已经有一个仓库在用了：https://github.com/fanye0220/APP （version.json 就放在那儿）。
1. 打开 https://github.com/fanye0220/APP
2. Add file -> Upload files
3. 把整个 tauritavern-miu-bridge 文件夹拖进去（要保留 tauritavern-miu-bridge 这一层目录名），
   提交到 main 分支
4. 回到酒馆 -> 扩展(Extensions)面板 -> Install extension
5. 粘贴这个地址：
   https://github.com/fanye0220/APP/tree/main/tauritavern-miu-bridge
6. 装完刷新酒馆页面（或重启酒馆），扩展面板里会出现「MIU 推卡桥接」

【安装方法 B：手动复制（桌面端 / 找得到数据目录时）】
把整个 tauritavern-miu-bridge 文件夹放到：
   <酒馆数据目录>/data/default-user/extensions/tauritavern-miu-bridge/
然后重启酒馆。
（安卓上酒馆的数据目录在 App 私有目录里，不好找，所以安卓优先用方法 A。）

【怎么用】
1. MIU 里开好接收服务（默认端口 8791）
2. 酒馆 -> 扩展面板 -> 「MIU 推卡桥接」
3. 端口填一样的（默认 8791），点「检测连接」，显示已连接
4. 点「推送全部角色卡」或「推送当前角色」
5. 切回 MIU -> 设置 -> TT 互联 -> 点「导入待接收卡片」-> 确认导入

【出问题先看这里】
- 找不到接收服务：回 MIU 重新点一次「开启接收服务」。
- 推一半失败：安卓会冻结后台 App，一次别推太多，推完马上切回 MIU 导入。
- 点了没反应/报网络错误：可能是酒馆外壳的 CSP 拦了 127.0.0.1，需要酒馆侧放开。
- 扩展面板里没出现「MIU 推卡桥接」：地址末尾必须是 /tree/main/tauritavern-miu-bridge，
  而且仓库里那一层目录名要和它一模一样。
