MIU 联动 —— TT 扩展安装说明
========================================

【这个文件夹是什么】
它本身就是「扩展」。里面 5 个文件：
  manifest.json   ← TT 靠它认出这是扩展（必须在文件夹最外层）
  index.js        ← 扩展本体
  style.css       ← 面板样式
  README.md       ← 说明
  安装说明.txt    ← 本文件

【第一步：传到 GitHub（只做一次）】
1. 打开 https://github.com/fanye0220/TT-tui
2. Add file -> Upload files
3. 把本文件夹里的这 5 个文件全部拖进去
   ★ 注意：不要再多套一层文件夹！manifest.json 必须在仓库最外层，
     也就是打开仓库首页就能直接看到它。
4. commit 到 main 分支

【第二步：在 TT 里安装】
1. 打开 TauriTavern -> 扩展（Extensions）面板
2. 找到「安装扩展 / Install extension」那一栏
3. 填地址：
      https://github.com/fanye0220/TT-tui
   ★ 只填仓库地址，不要带 /tree/main/ 之类的子目录路径，TT 会拒绝。
4. 安装完成后刷新 TT 页面（或重启 TT）
5. 扩展面板里出现「MIU 联动」，点开就是控制面板

【第三步：用起来】
1. MIU（安卓）-> 设置 -> TauriTavern -> 点「开启接收服务」
   （看到端口号，默认 8791）
2. TT -> 扩展面板 -> MIU 联动 -> 点「连接 MIU」
3. 点「推送当前角色」或「推送全部角色卡」
4. 切回 MIU -> 设置 -> TauriTavern -> 点「选择要导入的卡」-> 勾选后导入 -> 确认入库

【反着送：MIU -> 酒馆】  ← 这一版新增
1. MIU 里打开角色卡详情页，点右上角的纸飞机「发送到酒馆」，
   在弹出的选项里选「发送到酒馆（TT 联动）」
2. 卡会排进 MIU 的「待发送到酒馆」队列（在 设置 -> TauriTavern 能看到）
3. 切到 TT -> 扩展面板 -> MIU 联动 -> 点「接收 MIU 推送」
   （按钮上的数字就是排队张数，每 3 秒自动刷新）
4. 扩展把卡一张张取回来导入酒馆；导入成功的才从 MIU 队列移除，失败的留在 MIU 可以重试

【MIU 主动拉取：不切到 TT 也能拿卡】  ← 这一版新增
1. TT 保持运行（挂小窗最稳，安卓会冻结后台 App）
2. MIU -> 设置 -> TauriTavern -> 点「拉取 TauriTavern」
3. MIU 面板里搜卡名、勾选要哪几张 -> 点「拉取选中」
   列表里每张卡带一张 112px 小头像：只有划到眼前的那几行才会去生成，
   一次几 KB，不会为了看头像把整张卡拉下来，所以划起来不卡。
4. 这边自动导出送过去（TT 页面不用点按钮），MIU 收齐后自动进导入流程

   MIU 面板上会直接写清楚卡在哪一步（不用猜）：
   - 「酒馆扩展在线（N 秒前刚回过话）」= 通道是通的，正在等列表；
   - 「酒馆扩展一次都没回话」= 酒馆没连上（没点「连接 MIU」，或酒馆退到后台被冻结了）；
   - 直接显示一句失败原因 = 扩展回复了但列卡失败，按那句话排查。
   酒馆切回前台的一瞬间扩展会立刻补做一次，所以不用一直干等。

【为什么不用「填 127.0.0.1 端口」那种老办法】
正式版 TT 关掉了明文 HTTP，扩展直接 fetch 本机端口会被系统拦住。
TT 自带原生 MCP 客户端（走 Rust），本扩展就是用它连 MIU 的，
所以先要在 MIU 里把接收服务开起来。

【出问题先看这里】
- 「没找到 MIU 接收服务」：MIU 里的接收服务没开，或者被系统杀了，重开一次。
- 「联动通道暂时连不上」：MIU 被系统冻结了，分屏/锁定后台让它活着再试。
- 「这个 TT 版本没有联动能力」：TT 版本低于 2.3.0，需要升级 TT。
- 面板里没有「MIU 联动」：检查仓库最外层有没有 manifest.json，
  以及安装时填的是不是纯仓库地址。
- 「拉取 TauriTavern」一直转圈：先看 MIU 面板上那句状态（见上面第 4 步），
  多半是酒馆被退到后台了 -> 把酒馆切到前台（或挂小窗）就会立刻继续。
